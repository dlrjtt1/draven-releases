# DRAVEN — downloads

Installers for **DRAVEN**, a reference-matching tonal-balance analyser plug-in
(VST3 / AU / Standalone) by LABO 1557 (Dong-Gyun You).

DRAVEN is **distributed free of charge** as a personal project: no registration,
no licence key, no trial limit. There are no sales, donations or advertising.

- Download: see [Releases](https://github.com/dlrjtt1/draven-releases/releases)
- Installation notes, terms of use and third-party notices:
  https://dlrjtt1.github.io/researcher-site/draven.html

This repository holds release files only; the source code is not published here.
The installers are not code-signed yet; see the installation notes for the
Windows SmartScreen and macOS Gatekeeper warnings.

DRAVEN is provided "as is", without warranty of any kind.
